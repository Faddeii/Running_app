# Ритм — трекер бега (PWA)

Приложение для бега в духе Strava: точное измерение маршрута, время, темп, сохранение
тренировок, карта маршрута, достижения, календарь со стриком и планы тренировок по
методике **Джека Дэниелса (VDOT)** — системе, по которой готовятся профессиональные бегуны.

Работает в России (карты OpenStreetMap, без Google-сервисов), офлайн, ставится на телефон
как обычное приложение. Все данные хранятся **только на твоём телефоне**.

### Возможности

- **Интерфейс в стиле Strava** — светлая тема, фирменный оранжевый, чистые карточки.
- **Точный трекинг** — фильтр Калмана, отсев плохих точек, антидрожание (400 м = 400 м).
- **Голосовой помощник** — озвучивает дистанцию, время и темп прямо на бегу.
  Настраивается: как часто (по км или по времени) и что сообщать (⚙️ → Голосовой помощник).
- **Подсчёт кругов** для стадиона — автоматически по дистанции (400/200/1000 м) плюс
  кнопка «Отметить круг». Круги озвучиваются и показываются с темпом в деталях тренировки.
- **Планы тренировок (VDOT)** — все поля вводишь сам, каждое подписано:
  твой недавний результат → расчёт уровня, цель → проверка реалистичности, параметры плана.
- История, календарь со стриком, достижения и личные рекорды.

## Как получить приложение на Samsung S23 Ultra

GPS в браузере работает **только по HTTPS**. Поэтому файлы нужно выложить на бесплатный
хостинг с HTTPS. Ниже — два простых способа. Достаточно любого.

### Способ 1. Netlify Drop (самый быстрый, ~2 минуты)

1. На компьютере зайди на **https://app.netlify.com/drop**
2. Перетащи туда **всю папку** `Приложение для бега`.
3. Через несколько секунд получишь ссылку вида `https://random-name.netlify.app`.
4. Открой эту ссылку на телефоне в **Chrome**.

### Способ 2. GitHub Pages (бесплатно и навсегда)

1. Создай аккаунт на **github.com**, нажми **New repository**, назови, например, `ritm`.
2. Загрузи все файлы из папки (кнопка **Add file → Upload files**, перетащи всё, **Commit**).
3. Открой **Settings → Pages**, в разделе *Branch* выбери `main` и папку `/root`, **Save**.
4. Через минуту появится ссылка `https://ТВОЙ_ЛОГИН.github.io/ritm/`.
5. Открой её на телефоне в Chrome.

## Установка как приложение (на S23 Ultra)

1. Открой ссылку в **Chrome**.
2. Меню (три точки справа вверху) → **«Установить приложение»** (или «Добавить на главный экран»).
3. На главном экране появится иконка «Ритм». Запускай её — откроется на весь экран, как обычное приложение.

## Разрешения и настройки для максимальной точности

- При первом старте разреши доступ к **геолокации** → выбери **«Разрешить»**.
- В настройках телефона: *Настройки → Приложения → Chrome → Разрешения → Геолокация* —
  поставь **«Разрешить в любом режиме»** и включи **«Высокая точность»**
  (*Настройки → Локация → Геоданные Google → Высокая точность*, если есть).
- Отключи экономию батареи для Chrome (иначе система может «усыпить» GPS):
  *Настройки → Обслуживание батареи → Chrome → Без ограничений*.
- В самом приложении (⚙️) оставь включённым **«Не гасить экран во время бега»**.
- Первые 10–20 секунд стой на месте на **открытом воздухе** — приложение «прогревает» GPS
  (отбрасывает неточные точки), после чего счёт дистанции становится точным.

## Как обеспечивается точность (400 м = 400 м)

- Фильтр Калмана сглаживает координаты по их точности.
- Точки с плохой точностью (радиус ошибки > 25 м) **отбрасываются**.
- Защита от GPS-«скачков»: нереальные рывки (быстрее ~40 км/ч) игнорируются.
- Антидрожание: микросдвиги на месте (< 2.5 м) не засчитываются в дистанцию.
- Дистанция считается по формуле гаверсинуса между сглаженными точками.

## Локальная проверка на компьютере

```bash
py -3 -m http.server 8777 --bind 127.0.0.1
```
Затем открой `http://127.0.0.1:8777` в браузере (на localhost GPS тоже работает).

## Что внутри

| Файл | Назначение |
|------|-----------|
| `index.html` | Каркас интерфейса |
| `css/styles.css` | Оформление (тёмная тема) |
| `js/geo.js` | GPS: фильтр Калмана, гаверсинус, точный подсчёт дистанции |
| `js/stats.js` | Время, темп, калории, отрезки по км |
| `js/db.js` | Хранилище тренировок (IndexedDB) и настройки |
| `js/training.js` | Методика Дэниелса: VDOT, темпы, прогнозы, генератор плана |
| `js/tracker.js` | Запись пробежки, Wake Lock, голос по км |
| `js/ui.js` | Карты, календарь, стрик, достижения, отрисовка плана |
| `js/app.js` | Связка всего вместе |
| `sw.js` | Офлайн-кэш (приложение + тайлы карты) |
| `lib/` | Leaflet (карты), локально |
| `icons/` | Иконки приложения |

## Возможные доработки

- Нативная обёртка (для фонового трекинга с выключенным экраном на длинных забегах).
- Графики высоты/пульса (нужен доступ к датчикам/часам).
- Экспорт в GPX, синхронизация между устройствами.
- Автоотметка выполненных тренировок из плана и связка плана с историей.
